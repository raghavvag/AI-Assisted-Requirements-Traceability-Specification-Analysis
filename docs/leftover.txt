# MASTER CHECKLIST: Production Readiness
Project: AI-Assisted Requirements Traceability and Software Specification Analysis
Updated: 2026-10-16 (M1 implemented)
Design reference: docs/plan.md (each task gives the section it comes from, e.g. [§2.4])

How to use this file
- Do the tasks IN ORDER. Each task is sized to fit one coding session or one PR.
- Mark progress like this: [ ] = todo, [~] = in progress, [x] = done (put the date after it).
- A task is finished only when its "Done when" check is true AND `pytest` is green.

Decisions already made
- SRS formats: .docx + .pdf + .md/.txt
- Webhook demo: a local backend with a smee.io tunnel
- The Streamlit v1 app will be retired
- PR intent comes from the linked GitHub issue body (Closes #N), split into acceptance criteria
- Code-aware model: jinaai/jina-embeddings-v2-base-code, behind AlignmentScorer
- The LLM only explains results. It never sets a score or a verdict.
